# Программно-аппаратный комплекс (ПАК)
---
## Выполнил:
Фадеев Егор, Группа ИКС-432
---
Мобильное приложение в котором реализованы следующие задачи:
1. Калькулятор
2. Медиаплеер
3. GPS-трекер
4. Проверка подключения к серверу
5. Фоновый сервис для сбора данных о телефонии


## Архитектура:
- **Андройд приложение `(Kotlin)`**: https://github.com/nevertoomuch/AndroidProject
- **Серверная часть `(C++)`**: https://github.com/nevertoomuch/backend-server

## Описание модулей Андройд приложения:

- **MainActivity.kt**:
Главный экран приложения. Содержит меню из пяти кнопок, каждая из которых открывает соответствующий Activity: калькулятор, медиаплеер, местоположение, связь с ПК, данные телефонии.
---
- **CalcActivity.kt**:
Простой калькулятор с поддержкой четырёх арифметических операций (`+`, `-`, `*`, `/`), ввода десятичных чисел и обработки деления на ноль. Содержит пасхалку: при вводе `1337` выводит ссылку на статью о leet-speak.
---
- **MediaActivity.kt**:
Медиаплеер для воспроизведения аудиофайлов (`mp3`, `wav`, `m4a`) из папки `/Music` на внешнем хранилище. Поддерживает список треков, управление воспроизведением, перемотку через `SeekBar` и регулировку громкости. Запрашивает разрешение `READ_MEDIA_AUDIO`.
---
- **LocationActivity.kt**:
Отображает текущие GPS-координаты (широта, долгота, высота, время) и сохраняет историю позиций в файл `location_log.json` во внутреннем хранилище приложения. Время фиксируется по часовому поясу.
---
- **AndroidToPcActivity.kt**:
Отправляет тестовое сообщение на ПК по протоколу ZeroMQ (REQ-сокет, `tcp://192.168.56.1:5556`) и выводит ответ сервера на экран. Сетевое взаимодействие выполняется в отдельном потоке.
---
- **TelephonyActivity.kt**:
Управляет фоновым сервисом `TrackingService`. Отображает лог событий в реальном времени через `LocalBroadcast`. Позволяет экспортировать собранные данные телеметрии в файл `.jsonl` в папку `Downloads`.
---
- **TrackingService.kt**:
Фоновый сервис (`ForegroundService`), собирающий и отправляющий телеметрию каждые 2 секунды. Данные включают GPS-координаты и информацию о соседних сотовых сетях (LTE, GSM, NR — тип, идентификаторы, уровень сигнала). Отправка осуществляется по ZeroMQ на адрес `tcp://192.168.1.100:7777`, данные также сохраняются локально в `telemetry.jsonl`. Поддерживает команды `START`, `STOP` и `TEST_CONNECTION`.
